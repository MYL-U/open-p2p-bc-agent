## 与需求对应（必做/不做逐条映射）

### 必做项 → 承担部分

| 必做项 | 承担部分 |
|--------|----------|
| 1. 跑通官方 150M 完整离线推理 | 部分 2（环境）+ 3（权重）+ 4（推理） |
| 2. 仅 `--toy` / 官方分批参数获取数据 | 部分 1（数据层），脚本已确认 `--toy` 指向 toy 仓库、`--start/--end` 生成 `*batch_NNNNN*` 模式，全量下载需要显式去掉 `--toy` 且不设 `--end` 才会触发，双重防呆 |
| 3. 约 200 帧隔离测试集 + 无重叠校验 | 部分 1（划分与校验脚本） |
| 4. 指标书面定义 | 第 1 日报告附录 A（口径已按动作空间核实，见本报告"选型比较"） |
| 5. 逐帧对照 + 录屏 | 部分 5 + 6 |
| 6. 记录基线指标 | 部分 5 |

### 不做项 → 保障机制

- 不下载全量 `p2p-full-data`：数据层脚本确认只有去掉 `--toy` 且不传 `--end` 才下载全量，`day2_setup.sh` 固定使用 `--toy`。
- 课内不演示真机、不搭本地环境、不用 Recap：主线推理基于服务器 UDS 服务 + 离线帧输入，不接真机。
- 只用官方 150M 权重：权重层固定 `download_checkpoints.py 150M`。

### 可选扩展 → 前置条件（第 1 日报告附录 B 已列）

- 扩展 A（微调）：官方 150M.yaml 已含 Stage3 微调配置（lr 1e-4、200k 步、7 种数据增强），toy 子集直接可作微调数据；需额外算力。
- 扩展 B（文本指令）：`inference.py --input_text` 启动时启用、运行中不可切换（已核实），仅需推理服务以该参数重启。
- 扩展 C（推理性能）：`--use_full_inference`（无 KV cache 慢模式）与默认 KV cache 模式可对比，另有 `--metrics_window_seconds` 耗时上报。
- 扩展 D（自采数据）：数据需转成 `VideoAnnotation` protobuf 格式（官方 `recap` 工具生成，本课题服务器环境无 Recap，需自写序列化，工作量最高）。

## 选型比较

| 决策点 | 方案 A | 方案 B | 结论与理由 |
|--------|--------|--------|-----------|
| 环境管理 | 官方 `uv`（自动建 venv、锁文件解析 Python 版本） | 手动 `python3.10 -m venv` + pip 按 requirements 安装 | **选 A**。官方依赖由 `uv.lock` 统一管理，手动 pip 易版本漂移；`uv run` 一步到位，与官方 README 一致 |
| 推理预测采集 | 自研 UDS 客户端：逐帧发 `Frame` → 收 `Action` → 落盘 JSONL | 依赖 `--model_records_path`（服务端写 JSONL） | **选 A 为主**。`inference.py` 无 `--output` 参数，预测只能经 UDS 返回；`--model_records_path` 是服务端旁路记录（含 KV cache），可作为调试交叉验证，不替代主采集 |
| 对照基准来源 | 用官方 `playback.py` 回放人类标注作为对照服务器 | 直接读 toy 数据中的 `user_action` 与预测逐帧对齐 | **选 B**。playback 仅按帧序号回放、不支持 unknown action、且是额外一层服务；直接读标注文件更简单、可复核（第 5 天实施时确认 toy 数据字段对齐方式） |
| 鼠标位移评测对象 | 解码后的预测位移（`truncated_normal` 采样结果） | 模型输出的 bin 索引 | **选 A**。动作空间已核实：鼠标 x/y 先离散为 23/16 个 bin，推理默认以 `truncated_normal` 采样解码（X_STD=96、Y_STD=22）。皮尔逊相关系数计算对象为"解码后的像素位移"，与人类标注同为像素量纲才可比；这也解释了参考值≈0.5 的合理性 |
| 数据完整性 | 依赖 huggingface_hub 内部 ETag/断点续传 | 自写 MD5 校验 | **选 A + 兜底**。官方脚本无显式校验；以 `ls` 文件清单 + 加载 smoke test（权重能否被模型加载、toy 能否解析出帧）作为完整性自检 |
| 键鼠对齐判定 | 键盘按集合完全相等（max_keys=4 默认、20 类按键） | 键盘按逐键匹配 | **选 A**。`action_mapping.py` 已确认动作为"多键集合 + 鼠标按钮集合"结构，`_no_key=0` 填充，集合完全相等判定与官方动作空间一致 |

## 风险更新

- **环境风险**：基本消除——官方 uv 流程自动解析版本；残余风险是系统依赖（ffmpeg7、clang）需 apt 安装，已入 `day2_setup.sh`。
- **推理接口风险（新增，最重要）**：推理是 UDS 服务而非离线批处理脚本，主路径依赖自研客户端。应对：第 3 天优先实现客户端；`--model_records_path` 作为备选验证通道。
- **数据风险**：确认 `--toy` 与分批参数双保险；划分后仍做重叠校验。
- **真机/外设风险**：确认主线不需要真机与 Recap。
- **指标风险**：动作空间口径已按源码核实，皮尔逊相关对象明确为解码后位移。

## 附录：官方仓库工程结构梳理（已核实）

```
open-p2p/
├── pyproject.toml / uv.lock       # uv 统一管理依赖，自动解析 Python 版本
├── scripts/
│   ├── download_data.py           # 数据下载：--toy → elefantai/p2p-toy-examples；--start/--end → 分批 *batch_NNNNN*；全量须去掉 --toy 且不设 --end
│   └── download_checkpoints.py    # 权重下载：<150M|300M|600M|1200M> → HF guaguaa/open-p2p 对应子目录 → ./checkpoints/
├── config/policy_model/
│   └── 150M.yaml                  # 192×192 输入；10 层×1024 维×16 头；1 thinking token；attention_history_len=200×10；Gemma 文本 tokenizer；推理鼠标采样 truncated_normal；含 Stage3 微调配置
├── elefant/
│   ├── policy_model/
│   │   └── inference.py           # UDS 推理服务：收 Frame[192×192] → 回 Action(keys, mouse_buttons, mouse_delta_px)；--input_text 启动时启用；--model_records_path 服务端旁路 JSONL；--use_random_weights 免权重测试
│   ├── data/
│   │   └── action_mapping.py      # 键盘 20 类（_no_key=0, Space, 1-4, a/d/e/f/q/w/s/z, 方向键, Shift）；鼠标按钮 4 类；鼠标 x/y 离散 23/16 bin；解码 mean/conservative/truncated_normal；max_keys=4、max_mouse_keys=2（默认）
│   └── inference/script/
│       └── playback.py            # 开环回放人类标注（UDS 服务器），仅调试用，不含模型推理
└── checkpoints/150M/              # 下载后：model_config.yaml + checkpoint-step=*.ckpt
```

### 关键命令速查

```bash
# 环境（uv 自动建 venv）
uv run python scripts/download_data.py --toy                 # toy 子集 → ./dataset
uv run python scripts/download_checkpoints.py 150M           # 150M 权重 → ./checkpoints/150M
# 推理（两个终端：服务端 + 客户端）
uv run elefant/policy_model/inference.py --config checkpoints/150M/model_config.yaml \
  --checkpoint_path checkpoints/150M/checkpoint-step=00500000.ckpt
uv run python scripts/collect_predictions.py --dataset ./dataset --output predictions.jsonl   # 自研，第 3 天产出
# 对照组（可选验证通道）
uv run elefant/policy_model/inference.py ... --model_records_path model_records.jsonl
```
