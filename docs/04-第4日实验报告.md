## 7. 问题与 AI 沟通

**成功**：holdout 按「视频」划分而非按帧（避免同视频帧跨训练/保留集泄漏）；README 首跑标准量化到"ok=N 且 error 全 null"，可自校验。

**不成功的沟通**（重点记录）：
1. PowerShell 向 git 传**中文文件名参数**乱码（GBK 编码损坏），`git add "docs/03-….md"` 报 pathspec 不匹配 → 调整：改用通配符 `git add "docs/03-*.md"`，由 git 自身 glob，绕开编码问题。
2. 本机 git 报 `Author identity unknown` → 调整：不修改 git config（避免改全局配置），改用 `git -c user.name=… -c user.email=… commit` 单次注入身份，与历史提交作者一致。
3. 误判仓库未初始化（`list_dir` 不显示隐藏 `.git`）→ 用 `git status` 核实后更正，避免重复 init 损坏历史。
